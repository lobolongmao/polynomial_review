一、核心觀念整理

1. 一次與二次函數 (圖形與特徵)

  • 一次函數：$y=ax+b$。$a$ 決定斜率(走向)，$b$ 決定 $y$ 軸截距。
  • 二次函數：$y=ax^2+bx+c = a(x-h)^2+k$。$a$ 決定開口方向與大小，頂點 $(h,k)$ 決定極值。
  • 判別式與根：$D = b^2-4ac$。
    $D>0 \implies$ 與 $x$ 軸交於兩點 (相異實根)
    $D=0 \implies$ 與 $x$ 軸相切 (重根)
    $D<0 \implies$ 不與 $x$ 軸相交 (共軛虛根/恆正或恆負)
  • 💡 聯想：看到求「最大/最小值」，秒想配方法找頂點；看到「恆大於0」，秒想 $a>0$ 且 $D<0$。

2. 除法原理與餘式/因式定理

  • 除法原理：$f(x) = g(x)Q(x) + r(x)$，且 $\deg(r) < \deg(g)$。
  • 餘式定理：$f(x)$ 除以 $x-c$ 餘式為 $f(c)$；除以 $ax-b$ 餘式為 $f(\frac{b}{a})$。
  • 因式定理：若 $f(c)=0$，則 $(x-c)$ 是 $f(x)$ 的因式。
  • 💡 聯想：遇到除式是「一次式」，用餘式定理代入；遇到除式是「二次以上」，馬上寫出除法原理的橫式：$f(x) = (x-1)(x-2)Q(x) + ax+b$ 來解題。

3. 插值多項式 (Lagrange 與 Newton)

  • 核心精神：給定 $n$ 個相異點，必能決定一個次數 $\le n-1$ 的多項式。
  • 拉格朗日 (Lagrange)：利用構造法，一項為1、其餘為0的拼圖式寫法。多用於證明與理論。
  • 牛頓 (Newton)：$f(x) = a + b(x-x_1) + c(x-x_1)(x-x_2)$。適合循序漸進求解。
  • 💡 聯想：當題目給的 $x$ 值是連續整數或等差 (如 $f(1), f(2), f(3)$)，**絕對要用牛頓插值法**，計算量最小！

4. 勘根定理與虛根成雙

  • 勘根定理：若實係數 $f(x)$ 在區間 $[a,b]$ 連續，且 $f(a) \times f(b) < 0$ (一正一負)，則 $a, b$ 之間至少有一實根。
  • 虛根/無理根成雙：「實係數」多項式若有一根 $a+bi$，必有另一根 $a-bi$。「有理係數」若有一根 $a+\sqrt{b}$，必有另一根 $a-\sqrt{b}$。
  • 💡 聯想：如果題目特別強調「實係數方程式」，且透露了一個虛數根 $2+i$，你要自己主動補上它的雙胞胎兄弟 $2-i$。

5. 複數基本觀念

  • 定義：$z = a+bi$，$a$ 為實部，$b$ 為虛部，$i=\sqrt{-1}$。
  • 四則運算：加減法實部對實部，乘法如同分配律（記得 $i^2=-1$），除法需分母有理化（同乘共軛）。
  • $i$ 的週期性：$i^1=i, i^2=-1, i^3=-i, i^4=1$，四次一循環。

6. 多項式不等式 (穿針引線)

  • 解題SOP：化首項係數為正 $\to$ 因式分解 $\to$ 畫數線標根 $\to$ 判斷正負。
  • 奇穿偶彈口訣：因式的次方是奇數 (如 $(x-2)^3$)，曲線會穿過 $x$ 軸；次方是偶數 (如 $(x-3)^2$)，曲線碰到 $x$ 軸會反彈不穿過。
  • 💡 易錯點：記得分式不等式 $\frac{A}{B} \ge 0$ 要轉為 $A \times B \ge 0$，但要額外補上**「分母 $B \neq 0$」**的條件！

二、常見題型與破題技巧

🎯 題型一：不知如何下手的餘式假設法 (除式為二次式)

題目：已知 $f(x)$ 除以 $x-1$ 餘 3，除以 $x-2$ 餘 5，求 $f(x)$ 除以 $(x-1)(x-2)$ 的餘式。

破題技巧：除式是二次，餘式最高是一次。直接寫出除法原理橫式，並假設餘式為 $ax+b$。

1. 列式：$f(x) = (x-1)(x-2)Q(x) + (ax+b)$
2. 代根：
$f(1) = 0 + a(1) + b = 3 \implies a+b=3$
$f(2) = 0 + a(2) + b = 5 \implies 2a+b=5$
3. 解聯立：兩式相減得 $a=2$，代回得 $b=1$。
4. 故餘式為 $2x+1$。

🎯 題型二：牛頓插值法的威力

題目：三次多項式滿足 $f(1)=1, f(2)=2, f(3)=3, f(4)=5$，求 $f(5)$。

破題技巧：不用傻傻設 $ax^3+bx^2+cx+d$ 解四元聯立，善用牛頓插值的階層架構。

1. 假設 $f(x) = A + B(x-1) + C(x-1)(x-2) + D(x-1)(x-2)(x-3)$
2. 依序代入：
$f(1) = A = 1$
$f(2) = A + B(1) = 2 \implies 1+B=2 \implies B=1$
$f(3) = A + B(2) + C(2 \cdot 1) = 3 \implies 1+2+2C=3 \implies C=0$
$f(4) = A + B(3) + 0 + D(3 \cdot 2 \cdot 1) = 5 \implies 1+3+6D=5 \implies D = \frac{1}{6}$
3. 多項式現形：$f(x) = 1 + (x-1) + \frac{1}{6}(x-1)(x-2)(x-3)$。
代入 $x=5$ 得 $f(5) = 1 + 4 + \frac{1}{6}(4 \cdot 3 \cdot 2) = 5 + 4 = 9$。

🎯 題型三：高次多項式降次求值 (利用除法)

題目：已知 $x = 1+\sqrt{2}$，求 $x^3 - x^2 - 3x + 5$ 的值。

破題技巧：千萬不要把 $1+\sqrt{2}$ 直接帶入三次方！先製造二次方程式，再用長除法求餘式。

1. 製造除式：移項 $x-1=\sqrt{2}$，兩邊平方 $x^2-2x+1 = 2 \implies x^2-2x-1 = 0$。
2. 多項式除法：將 $(x^3 - x^2 - 3x + 5)$ 除以 $(x^2-2x-1)$。
3. 除法原理：$x^3 - x^2 - 3x + 5 = (x^2-2x-1)(x+1) + 6$。
4. 妙用：因為已知 $x^2-2x-1 = 0$，所以前面整包變成 0！
答案就是餘式 6。
